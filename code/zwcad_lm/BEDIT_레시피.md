# 플렉시블 블록 저작 레시피 — 2차선 레일 리사이즈

목표: `rail2_base.dxf` 의 정적 블록 `RAIL2` 를 **끌면 길이가 변하는 다이나믹/플렉시블 블록**으로 만든다.
현재 .NET 플러그인의 "양 끝 그립 드래그 리사이즈"를 코드 없이 재현.

> ## ✅ 저작은 ZWCAD LM 에서 직접 한다 (2026-07-06 정정 — 실물 확인됨)
> **오해 정정**: 앞서 "LM 저작 불가"는 오판이었다. LM 은 AutoCAD 의 `BAUTHORPALETTE` **명령**이 없을 뿐,
> 저작 도구는 **`블록 편집기` 리본 탭 → "작업 매개 변수" 패널**(점·이동·극좌표 이동·속성 정의·가시성 상태)에 있다.
> ZWCAD LM 2026 Trial 에서 `거리1`(선형/거리 파라미터)+`신축`(Stretch)+`이동`(Move) 배치 성공 확인.
>
> **워크플로 (AutoCAD 불필요):**
> 1. **ZWCAD LM** 에서 `rail2_base.dxf` 열기 → `BEDIT RAIL2` → 리본 `블록 편집기` 탭 → "작업 매개 변수" 로 저작 → **DWG 저장**
> 2. 그 DWG(플렉시블 블록)를 **다른 LM 사용자에게 복사 배포** → 삽입 후 드래그 리사이즈 (저작도구 불필요, 순수 소비)
>
> 아래 단계의 "블록 저작 팔레트/BAUTHORPALETTE" 언급은 **리본 `블록 편집기` 탭 → 작업 매개 변수 패널** 로 대체해 읽으라.

## 0단계 (필수·2분): 거리 배수 지원 확인 [T2]

조인트 **비율 재배치**와 (3차선의) **station 중앙 고정**은 "거리 배수(Distance multiplier / 거리 승수)"에 의존한다.
착수 전에 LM이 이걸 지원하는지 먼저 확인:

1. 아무 블록이나 `BEDIT` → 블록 편집기 진입
2. 매개변수 팔레트에서 **선형(Linear) 매개변수** 하나 추가
3. 동작 팔레트에서 **이동(Move) 동작** 하나 추가해 매개변수에 연결
4. 그 이동 동작을 선택 → **속성(Properties)** 창에 **"거리 배수 / Distance multiplier"** 항목이 있고 편집 가능한가?

- **있음** → ✅ 아래 "정밀 버전"으로 진행(조인트 비율 재배치까지 100% 재현)
- **없음** → ⚠️ "단순 신축 버전"만 가능(조인트는 제자리, 위쪽만 늘어남). 정밀 거동이 꼭 필요하면 그건 **LISP `RAILLEN` 명령**으로 처리(플렉시블 블록은 빠른 드래그용으로만).

## 기준 지오메트리 y 좌표 (스트레치 프레임 잡을 때 참고)

base length = 30000, 조인트 2개. 축 = +Y, 하단 끝 = y0, 상단 끝 = y30000.

| 요소 | y | 리사이즈 시 거동 |
|---|---|---|
| 하단 끝(캡·throat) | 0 ~ 1180 | **고정**(base) |
| 조인트 #1 중심 | 10000 (= L·1/3) | 위로 Δ·**1/3** 이동 |
| 조인트 #2 중심 | 20000 (= L·2/3) | 위로 Δ·**2/3** 이동 |
| 상단 throat/캡 | 28820 ~ 30000 | 위로 Δ·**1.0** 이동 |
| 세로 edge 2개 | 0 → 30000 | **신축**(상단 끝만 이동) |

(Δ = 드래그로 늘린 길이)

## 정밀 버전 (거리 배수 지원 시)

### 1. 블록 편집기 진입
`OPEN rail2_base.dxf` → `BEDIT` → `RAIL2` 선택 → 편집기 진입.

### 2. 선형 매개변수 추가 (길이축)

**먼저 "블록 저작 팔레트"를 띄운다** (안 보이면 파라미터 추가 불가):
- 블록 편집기 안에서 명령창에 **`BAUTHORPALETTE`** 입력 → Enter
- 팔레트 창이 뜬다 — 탭: **매개변수(Parameters) / 동작(Actions) / 매개변수 세트 / 구속**

선형 매개변수 배치:
- **매개변수 탭 → 선형(Linear)** 클릭
- "시작점" → 좌표 타이핑 **`0,0`** Enter (하단, 고정단)
- "끝점" → **`0,30000`** Enter (상단, 이동단)
- 레이블 위치는 옆 아무 데나 클릭 → "거리(Distance)" 매개변수 + 그립 생성
- 매개변수 선택 → 속성에서 그립 수 = **1** (상단만) 로. 이름 "Length".
  - (양 끝 다 끌고 싶으면 그립 2개로. 단 하단 끌면 삽입점도 움직여야 해서 복잡 → 우선 상단 1개 권장)

> ⚠️ `BAUTHORPALETTE` 를 쳐도 팔레트가 안 뜨거나 매개변수/동작 탭이 비어있으면 → **LM이 Flexiblock 저작 제한**. 이 경우 **AutoCAD 2026에서 저작(선형+신축+이동) 후 DWG 저장 → LM에서 Flexiblock으로 변환·사용**. (LM은 AutoCAD 다이나믹블록→Flexiblock 변환 지원)

### 3. 신축(Stretch) 동작 — 상단 그룹 + edge 신축
- 동작 팔레트 → **신축(Stretch)** → 위 선형 매개변수의 **상단 그립**에 연결
- **신축 프레임**(크로싱 상자)을 **y ≈ 25000 위 전체**를 감싸게 그린다
  (조인트#2(20000)와 상단 throat(28820) 사이를 자르는 위치)
- 대상 선택: 프레임 안/걸치는 객체 모두 선택
  - 완전히 안에 든 것(상단 캡 호 2개 + 상단 throat 바/호) = **이동**
  - 프레임에 걸친 것(세로 edge 2개) = **신축**(상단 끝점만 이동)
- 거리 배수 = **1.0** (기본)

### 4. 이동(Move) 동작 × 조인트 수 — 비율 재배치
조인트마다 하나씩:
- 동작 팔레트 → **이동(Move)** → 같은 선형 매개변수(상단 그립)에 연결
- 대상 = 해당 조인트의 **바 2개 + 호 4개**(예: 조인트#1 = y 9675~10825 근처 6개 객체)
- 속성 → **거리 배수**:
  - 조인트 #1 = **0.3333** (= 1/3)
  - 조인트 #2 = **0.6667** (= 2/3)
  - 일반식: 조인트 i(1부터) = **i / (조인트수 + 1)**

### 5. 저장·테스트
- 편집기 닫고 저장 → 블록 선택 → **상단 그립 드래그**
- 확인: 상단이 늘어나고, 조인트가 항상 1/3·2/3 지점을 유지하며 재배치, 조인트/캡의 호 반경(r500)·바 폭은 불변.

---

## 단순 신축 버전 (거리 배수 미지원 시)

2·4단계에서 거리 배수를 못 쓰므로:
- **2단계**(선형 매개변수) + **3단계**(상단 신축) 만 수행.
- 결과: 위쪽만 늘어나고 **조인트는 하단 기준 제자리**(재배치 없음). 형상 왜곡은 없음(호·바 불변).
- 조인트 비율 재배치가 업무상 꼭 필요하면 → 그 부분만 **LISP `RAILLEN` 재생성 명령**으로 처리하고, 플렉시블 블록은 "빠른 눈대중 드래그" 용도로 병행.

## 3차선(RAIL3) 은?
동일 원리. 차이점만:
- 내부 station 은 **이동(Move) 동작 + 거리 배수 0.5** (길이/2 위치 = 중앙 고정)
- 양 끝 그룹(캡·throat·부분 중앙 edge·끝 ramp)은 상단=신축 1.0 / 하단=고정
- 3차선 기준 지오메트리 DXF 는 요청 시 `RailGeom3.Build` 이식본으로 별도 생성.

## LM 소비 검증 (AutoCAD 저작 후 LM 에서 확인)
저작(AutoCAD)은 되더라도, **LM 이 그 다이나믹 블록을 제대로 "스트레치"하는지**는 별개로 확인해야 한다:
1. 가장 단순한 **선형+신축(Stretch)만** 넣은 블록으로 먼저 DWG 저장 → LM 에서 열어 그립 드래그 → 늘어나는지 확인.
2. 되면 이동(Move)+거리배수까지 넣은 완성본으로 확장. **거리배수 액션을 LM 이 존중하는지**가 핵심(안 되면 조인트 재배치가 LM 에서 안 먹힐 수 있음).
3. LM 에서 처음 열 때 "노란 번개" 아이콘이면 → LM 지시대로 Flexiblock 으로 **변환** 후 사용.

## 배포
완성한 플렉시블 블록이 든 DWG 를 **블록 라이브러리(팔레트)** 나 템플릿에 넣어 배포.
리본 버튼은 별도로 `CUI` 로 "블록 삽입" 매크로를 걸면 현재 리본과 동일한 UX.
