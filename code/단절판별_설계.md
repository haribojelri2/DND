# 레일 단절 판별 설계 — 의도된 단절 vs 도면 오류

작성 2026-11-05. 계획서(D&D Tips 상세계획 V5) 11·14쪽 "예외 패턴 대응 기술" 중 **의도된 단절 판별 기준**을 어떻게 만들지 정리한 안.
아직 구현 전. 지금 구현된 것은 "연결 끊긴 슬롯 경고"(MAP 단계)와 "8 mm 이내 끝점 자동 연결"(치환 단계)뿐이다.

## 1. 무엇을 '단절'로 보나

| 대상 | 찾는 곳 | 지금 상태 |
|---|---|---|
| 막다른 끝(dead end): 선·호 끝점에 다른 선·호가 하나도 안 붙음 | 치환 전처리 그래프 | 8 mm 이내면 같은 점으로 봄, 그 이상은 그대로 |
| 연결 끊긴 슬롯: 모듈 슬롯이 모듈 밖과 안 이어짐 | MAP 생성(module_map) | **경고 구현(2026-11-05)** |
| 막힌 Node: MAP 에서 들어오기만/나가기만 하는 Node | MAP 검사 | 검사 스크립트만 있음 |

OHT 레일은 원칙적으로 전부 순환(한 바퀴 돌아 나올 수 있어야 함)이므로, 막다른 끝은 **설비에 붙는 자리이거나 오류**다.

## 2. 판별에 쓸 근거 (점수식)

각 막다른 끝 E 에 대해 아래 근거를 모아 점수로 판정한다. 한 가지 근거만으로 정하지 않는다.

| 근거 | 계산 | 의도 쪽 | 오류 쪽 |
|---|---|---|---|
| ① 짝 끝점 | E 앞쪽(진행 방향 연장선) 반경 G 안에 다른 막다른 끝 F 가 있나 | 없음 | 있음 — 특히 E·F 가 한 직선 위, 방향 반대 |
| ② 틈 크기 | dist(E, F) | 큼(> 수백 mm) | 작음(≤ 50 mm 는 거의 확실한 오류) |
| ③ 접선 연속 | E·F 의 접선이 이어지나(각도 차) | — | 1° 이내면 오류 |
| ④ 같은 레이어·색 | E·F 가 같은 레일 레이어 | — | 같으면 오류 쪽 + |
| ⑤ 주변 설비 | E 에서 반경 D 안의 STB·EQ Port·Stocker·투입구 블록/레이어 (CadToMap_Input 의 Layer_EqPort.csv·Layer_StbPort.csv 재사용) | 있음 | 없음 |
| ⑥ 그래프 맥락 | E 를 지우면 끊기는 구간 길이, 순환 안에 있나(강연결 성분) | 짧은 가지(스텁) 끝 | 큰 순환을 둘로 쪼갬 |
| ⑦ 모듈 맥락 | E 가 모듈 슬롯이고, 마주 보는 슬롯과 겹쳐 짝이 안 잡혔나 | — | 겹침이면 **도면 설계 문제**(분기 옆 차선 이동) |

## 3. 분류 결과 (4가지)

| 분류 | 조건(초안) | 처리 |
|---|---|---|
| A. 오류 — 자동 연결 | ①있음 + ②≤ 50 mm + ③1° 이내 + ⑤없음 | 끝점을 이어 붙이고 이력에 기록 |
| B. 오류 — 확인 필요 | ①있음 + ②50~500 mm, 또는 ⑦모듈 겹침 | 연결하지 않고 경고(빨강), 위치·후보 제시 |
| C. 의도된 단절 | ①없음 + ⑤설비 있음 + ⑥스텁 | 정상으로 기록(보정 대상 아님), MAP 에 Port 연결 후보로 표시 |
| D. 불확실 | 위에 안 맞음(①없음 + ⑤없음 등) | 경고(노랑), 사람이 판단 |

임계값(G, D, 50 mm, 500 mm, 1°)은 회사별 Template 처럼 설정으로 뺀다.

## 4. 출력

- 판정 결과 표(CSV): 위치, 분류(A~D), 근거 값(틈, 각도, 주변 설비 이름·거리), 적용한 보정
- 로그·이력: "자동 연결한 곳"은 원래 좌표를 남겨 되돌릴 수 있게(계획서 '예외처리 로그·복구 기능')
- 플러그인 표시: 마진 검사처럼 위치에 원 표시(분류별 색)

## 5. 검증 방법

1. 실제 도면에서 설비 접속 자리(의도된 단절)를 사람이 표시한 정답 목록을 만든다(도면 몇 장, 자리 수십 곳).
2. FAB30 30장처럼 설비가 없는 도면은 B(모듈 겹침)·A(미세 틈)만 나와야 한다 → 오탐 확인용.
3. 일부러 1~50 mm 틈·어긋남을 넣은 시험 도면으로 A 분류·자동 연결을 확인한다.
4. 정답 대비 분류 정확도(분류별 정밀도·재현율)를 성능평가 체계 KPI 에 넣는다.

## 6. 필요한 것 (사용자 확인)

- 설비 블록·레이어 이름 규칙(회사마다 다름): 지금 CadToMap_Input CSV 로 받는 STB·EQ Port 외에 Stocker·투입구 이름
- 의도된 단절이 실제로 있는 도면 샘플(지금 testlayout FAB30 에는 설비 블록이 없음)
- 자동 연결을 허용할 최대 틈(기본 50 mm 제안)
