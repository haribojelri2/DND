■ ZWCAD LM 레일 플러그인 이식 — 진행 보고

□ 1. 목표
   기존 AutoCAD 2026용 .NET 레일 플러그인(RailPlugin)의 기능
   — 2차선 레일 자동 생성 및 길이 조절(그립 드래그 + 명령어) —
   을 ZWCAD LM 2026 에서 재현.

□ 2. 환경 조사 결과 (핵심 제약)
   - ZWCAD LM 은 .NET 플러그인 개발을 지원하지 않음.
     (.NET / ZRX / VBA 는 상위 에디션 Professional / MFG 전용 — 공식 제품 비교표로 확인)
   - LM 이 지원하는 것: LISP(vlax 포함) + 플렉시블 블록(다이나믹 블록) + CUI(리본 커스터마이징)
   - 따라서 기존 .NET 코드를 그대로 이식할 수 없고,
     LISP + 플렉시블 블록으로 재구현하는 방향으로 진행.

□ 3. 완료 사항
   1) 레일 지오메트리 정립
      - 2차선 레일의 치수·관계식 정리(호가 바·edge 에 정확히 맞물리도록 재계산).
      - Python 으로 기준 형상 자동 생성.
   2) 플렉시블 블록 (그립 드래그 리사이즈) — 원래 플러그인과 동일하게:
      - 양방향 그립: 위쪽 그립(아래 고정) / 아래쪽 그립(위 고정) 각각 드래그로 길이 조절.
      - 조인트 비례 이동: 길이 변경 시 내부 조인트가 비율(1/4, 3/4)을 유지하며 재배치
        — 양방향 모두 정상 확인.
   3) 명령어 방식 (LISP)
      - DRAWRAIL2(레일 삽입), RAILLEN(길이 변경) 구현.
      - 명령어 리사이즈는 최소 길이로 자동 제한(너무 짧으면 겹치므로 하한 적용).
      - 순수 LISP 재생성 방식은 조인트 비례가 코드로 100% 정확.
   4) 배포 패키지
      - 다른 LM 사용자가 설치·사용하도록 파일 세트(블록 + LISP + 설치안내) 구성.

□ 4. 남은 문제 / 한계
   1) 그립 리사이즈 시 최소 길이 미보장 (겹침 문제)
      - 그립을 너무 짧게 끌면 양 끝(throat)과 조인트가 겹쳐 형상이 깨짐(역전).
      - 명령어 방식은 하한으로 자동 제한되나, 그립은 플렉시블 블록 파라미터에
        최솟값을 직접 걸어야 하며, 이 부분이 아직 완전히 해결되지 않음.
   2) 리본 배포의 어려움
      - ZWCAD LM 은 리본 커스터마이징을 파일로 내보내는 기능이 없음(메인 설정 파일에 묶임).
      - → 리본 버튼은 각 PC 에서 직접 생성해야 함(약 5분, 안내 제공).
      - 명령어 자체는 리본 없이도 동작하므로 기능상 문제는 아님.
   3) 명령어 리사이즈의 기준점 제약
      - RAILLEN(명령어)으로 길이 변경 시, 두 파라미터 중 한쪽(위 고정)만 코드(vlax)로 제어되고
        다른 쪽(아래 고정)은 코드에 반응하지 않음.
      - → 명령어 리사이즈는 위쪽이 고정됨. (마우스 그립은 양방향 정상.)
   4) 플렉시블 블록 저작은 수작업
      - 파라미터/동작은 어떤 CAD 에서도 코드로 생성 불가(공개 API 없음).
      - → 블록은 수작업으로 저작, 코드 재생성은 불가.

□ 5. 결론
   - 핵심 기능(그립 양방향 리사이즈 + 조인트 비례 + 명령어 생성/리사이즈)은
     ZWCAD LM 에서 재현 완료.
   - 남은 것은 (1) 그립 최소 길이 미보장(겹침), (2) 리본 배포 편의성,
     (3) 명령어 리사이즈 기준점 — 보완이 필요한 사항임.
   - 참고: 현재 2차선 기준. 3차선은 동일 방식으로 확장 예정.
